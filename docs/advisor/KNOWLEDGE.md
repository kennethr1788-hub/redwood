# Advisor guidance

Advisor retrieves at most three of 18 bounded runtime help cards for each question. Their owner-source pointers and 49 support intents are defined in `knowledge.mjs`. They are guidance, not current account evidence or permission to execute. Native advice requires the evaluator's own supported Codex account; deterministic local help remains available.

This distribution excludes internal maintenance registers and their provenance checks. The public verifier checks runtime retrieval, boundaries, compatibility and synthetic responses; it does not certify those excluded records.
