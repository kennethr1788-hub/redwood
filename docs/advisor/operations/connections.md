# Connections and native accounts

TOPIC: operations.connections
PURPOSE: Explain observed connection/capability state without inferring access, billing or permission.
WHEN TO USE: Codex, Higgsfield, Doctor, runtime selection, quota or a missing account observation.
REQUIRED FACTS: Named provider; current Doctor row; selected mode/capability; observation scope/freshness; actual native-client status when supplied.

STABLE PRINCIPLES
DETECTED is not AUTHENTICATED, AUTHENTICATED is not VERIFIED, and VERIFIED is not AUTHORIZED. A positive label is scoped evidence; fresh UNKNOWN outranks an old discussion saying ready. Status-only Advisor context cannot establish every capability, billing entitlement or account permission. Official native account setup belongs to the provider; never paste credentials into Advisor.

DECISION TREE
Identify the provider and intended capability. Read the matching current observation; absent, stale or unrelated observations remain UNKNOWN. Explain the exact missing prerequisite and one existing owner/native-client check. Optional connection trouble does not make local Build, Present or Grow unusable. The Doctor summarizes supplied observations; it does not authenticate, submit jobs or certify a balance.

Advisor's Codex path uses the existing ChatGPT account for bounded advice. The same account can support Build's separate coding workflow. No API key, second subscription, model wallet or alternate-provider fallback is required by this path. Unavailable native runtime, invalid output or timeout returns Local Advisor help. Native account usage remains subject to provider limits; subscription access is not proof every API or media action is free.

Higgsfield VIDEO_GENERATION support is declared by the integrated media contract. Image generation is not declared by this source. AGENT_ACCOUNT uses ACCOUNT_CREDITS; DIRECT_API uses API_METERED billing. These are distinct modes, not interchangeable entitlements. OFFLINE_QUALIFIED is fixture qualification; NOT_RUN and UNKNOWN establish no live readiness. A separate leaf qualified normal account submit, but that result does not prove this Advisor source includes the leaf or that this user's current capability is verified. Read current Connections for mode/capability/scope. Provider output remains UNREVIEWED; Advisor never generates, imports or publishes it automatically.

COMMON FAILURE MODES
Inventing a Connect button, promoting installation into sign-in, borrowing another capability's proof, asking for keys, treating a model answer as auth evidence or recommending a new provider after one error. Claude may remain a manual prompt target; it is not required for a Codex-only user. ElevenLabs is outside required competition functionality, not a setup prerequisite.

STOP CONDITIONS: Missing/expired observations, unknown billing, uncertain submission result or credential request. Reconcile before retry and continue supported local work where possible.
WHAT NOT TO CLAIM: Connected, included/free, generated, authorized or published without current matching evidence.
NEXT ACTION / OUTPUT SHAPE: Supplied provider state; capability/billing unknowns; preserved local path; one official/current check.
