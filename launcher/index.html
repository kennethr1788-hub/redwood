Local storage and project ownership

Up to 16 %LABEL_BUILD% project/id navigation pointers and one bounded %LABEL_ADVISOR% checkpoint are kept in this browser. The checkpoint contains only project/conversation IDs, coding-agent and response-style preferences, and topic IDs. Questions and answers are not saved. Clear site data to forget them. Project context, credentials, readiness and completion are not stored here. Each product owns its project files and current state.
